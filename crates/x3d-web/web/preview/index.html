How to test

    
    
      
  • EXAMINE: drag with the left mouse button (one finger) to turn the world. Use the wheel (two-finger pinch) to zoom.
    • 
      
  • WALK and FLY: load "Navigation", select WALK or FLY, then drag up or down to move and left or right to turn.
    • 
      
  • TouchSensor: in "VRML97 basic", press the red box. "Touch.isActive" is TRUE while you press.
    • 
      
  • PlaneSensor: in "VRML97 basic", drag the blue box. It moves in its plane.
    • 
      
  • TimeSensor: the green cone (VRML97) and the pyramid (X3D) turn continuously.
    • 
      
  • JavaScript API: the color buttons set the "ColorTarget" Material field.
    • 
      
  • Inline, EXTERNPROTO and textures: load "Resources". You see a checker box, a striped sphere (Inline) and a magenta box (EXTERNPROTO).
    • 
      
  • Failed URL: load "Missing world". The status shows the error and the last world stays. Then load another world.
    • 
    

    
Script nodes are off on this page. The viewer keyboard and context menu work as in X_ITE where the engine supports them.
