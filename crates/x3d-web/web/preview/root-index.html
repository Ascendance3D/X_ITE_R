Browser Preview 0.1.0

X3D and VRML97 worlds, run by a Rust engine in the browser.

X_ITE_R is a port of the X_ITE browser to Rust. The engine runs as WebAssembly. It parses the world, runs the events, sensors and navigation, and draws with WebGPU. When the browser has no WebGPU, the same renderer draws with WebGL2.

Pre-release for testing. It is not a full replacement for X_ITE 16.5.0. What works and what does not.

Limits

On WebGL2

  • No shadows and no volume scattering.
  • No GaussianSplats.
  • Thick particle lines are made on the CPU.
  • At most 64 lights and 8 TextureProjector nodes per frame.
  • Instanced shapes are drawn in windows of 84 instances.

Missing

Not available

  • WebXR.
  • WebGPU compatibility mode for OpenGL ES 3.1 class GPUs.
  • Most X3DBrowserContext functions and the WebGL rendering properties.
