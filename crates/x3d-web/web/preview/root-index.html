X_ITE_R Browser Preview 0.1.0

A pre-release of the X_ITE_R browser runtime (Rust, WebAssembly, WebGPU). It is not a full replacement for X_ITE 16.5.0.

  • Preview test page: test worlds, navigation, sensors, JavaScript API
  • Example: one Box and the JavaScript API
  • Example: EXAMINE, TouchSensor, PlaneSensor, Anchor, Inline, texture
  • README.md (deployment), COMPATIBILITY.md, docs/API.md, build-info.json, SHA256SUMS

Needs a browser with WebGPU: Chrome or Edge 113 or later on a desktop.
